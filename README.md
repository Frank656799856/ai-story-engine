# Story — AI 驱动的剧情副本游戏系统

用大模型现场生成一个可玩的世界：AI 造城、NPC 有记忆、任务有判定、剧情有终局。

## 这是什么

输入一段世界观设定，AI 自动构建完整的副本世界——地点、NPC、人物关系、埋藏的秘密、任务链、多结局，然后你以玩家身份进入其中对话、探索、推进剧情，直至抵达某个结局。

后端是游戏核心，前端是薄薄一层显示界面：

- **造城流水线**：世界观 → 生成（剧本/角色/任务/秘密）→ 审稿 Agent 打分 → 不达标退回修订，产出结构化剧本 JSON
- **导演状态机**：所有剧情状态（任务进度/秘密揭示/NPC 位置/好感）由程序裁决落盘——AI 只能提议（工具调用 + 白名单校验），不能直接改世界
- **NPC 长期记忆**：每条对话自动摘要入库、检索召回，NPC 记得你们之间发生过什么
- **任务系统**：flag 注册制（接取条件/完成条件表达式），任务面板实时可查，完成奖励由导演发放
- **群场演出**：多个 NPC 同场各自作答，支持点名、插话、私聊（同地点硬校验）
- **多结局**：根据 flags 组合触发不同 ending

## 运行

```bash
pip install flask requests
# 在 config.txt 配置 LLM API（DeepSeek/OpenAI 兼容格式，含密钥——不入库）
python app.py
# 浏览器打开 http://localhost:5004
```

## 目录结构

```
agent/     AI 流水线（A1 检索 → A2 深想 → A3 台词 → A4 记忆/状态）+ 提示词集中管理
story/     导演核心：剧本构建器、状态机、旁白、存档读写
memory/    长期记忆系统（摘要入库 / 索引检索）
tools/     游戏库、时间、剪贴板查重、角色包导入导出等
static/    开发者面板（trace 追踪 / 调试视图）
app.py     Flask 入口（API 服务）
```

## 说明

- 本项目为独立子系统，依赖外部 LLM API（OpenAI 兼容接口均可，密钥自备）
- 生成的副本数据（存档/记忆/日志）均在 `data/` 下，不入版本库
